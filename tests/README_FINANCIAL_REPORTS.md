# Тестовые финансовые отчеты

Эта папка содержит примеры CSV файлов для тестирования функции обновления финансовых отчетов.

## Файлы

### 1. `financial_report_test.csv`
Универсальный тестовый файл со смешанными данными (квартальные и месячные периоды).

### 2. `financial_report_daily.csv`
Пример ежедневного отчета с данными за конкретные даты (30-31 октября 2025).

### 3. `financial_report_monthly.csv`
Пример ежемесячного отчета с данными за октябрь и ноябрь 2025 года.

### 4. `financial_report_quarterly.csv`
Пример квартального отчета с данными за Q4 2025 и Q1 2026 (план).

## Формат CSV

Каждый файл должен содержать следующие колонки:

- `period` - Период (Q1 2025, 2025-10, 2025-10-30 и т.д.)
- `department` - Отдел
- `type` - Тип затрат (materials, labor, transport, equipment, it, quality, other)
- `amount` - Сумма (в рублях)
- `comment` - Комментарий (опционально)
- `status` - Статус (В рамках бюджета, Превышение стоимости, Экономия)

## Как использовать

1. Откройте страницу "Финансово-аналитический модуль" в браузере
2. Нажмите кнопку "Обновить отчёт"
3. Выберите тип отчета (ежедневный/ежемесячный/ежеквартальный)
4. Загрузите соответствующий CSV файл
5. Укажите период (например: 2025-Q4 или 2025-10)
6. Нажмите "Загрузить"

## Примечания

- Файлы должны быть в UTF-8 кодировке
- Поддерживается только формат CSV
- При загрузке старые данные за указанный период будут заменены новыми
